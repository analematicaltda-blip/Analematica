# Frontends del sistema

- `ANALEMATICA-FRONTEND/`: landing, ingreso del dueño y consola de Analemática.
- `SGA-CD-WEB.git/`: interfaz web de SGA-CD.
- `SGA-ERP-TUR-FRONTEND/`: interfaz ERP turística.
- `SGA-TUR-FRONTEND/`: interfaz turística.

Las cuatro interfaces están aquí. Los servicios están en `../BACKEND/`.
[deployment/README.md](deployment/README.md) explica el arranque de las cuatro
vistas locales por HTTPS, accesos privados y los límites funcionales actuales.
La configuración de revisión no publica carpetas de código, documentación privada
ni claves como archivos estáticos. No despliega producción ni simula un login ERP.
