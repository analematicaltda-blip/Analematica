# Frontends del sistema

- `SGA-CD-WEB.git/`: versión web de SGA-CD.
- `SGA-ERP-TUR-FRONTEND/`: interfaz ERP turística.
- `SGA-TUR-FRONTEND/`: interfaz turística.

Analemática mantiene su interfaz dentro de `Analematica/Frontend` y sus servicios
en `Analematica/backend`. Se actualizaron las rutas de publicación, Compose,
pruebas y referencias a estos tres proyectos conservando sus contenidos.
El traslado no inicia servicios ni modifica bases de datos.
